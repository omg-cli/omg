### Fedora

- Fedora package sync, install and preview commands redact credentials from DNF mirror diagnostics. The terminal still shows the repository, failure reason and transaction progress.
- Fedora status and package search better reflect native RPM and DNF state. The daemon refreshes its package index when enabled repositories or local metadata change.

### Debian and Ubuntu

- Native APT downloads use libapt's default progress interval, reducing terminal output and CPU use while a mirror is slow.

### Advisory review

- OMG-managed npm tool installs assess the resolved package versions before materializing the dependency tree. Advisory warnings link to the disclosure and require explicit acceptance in the terminal.

### Release verification

- The release verifies the exact Linux and macOS archives from protected CI, runs native smoke tests, and signs the archives and SBOM with GitHub build provenance. The Cloudflare version marker advances after the uploaded archives and checksums pass readback.
- Debian and Ubuntu smoke tests share verified APT indexes across three fresh containers for search, install and removal. Setup failures preserve evidence and block publication.
