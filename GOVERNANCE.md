# Governance

OMG is a maintainer-led open source project hosted by the `omg-cli` GitHub organization. The lead maintainer is [@PyRo1121](https://github.com/PyRo1121); path ownership is recorded in [CODEOWNERS](.github/CODEOWNERS).

Contributors propose changes through issues, discussions and pull requests. Maintainers make technical and release decisions after reviewing the evidence, compatibility impact and security implications. Decisions and their reasons belong in the relevant public issue or pull request. Suspected vulnerabilities follow the private reporting process in [SECURITY.md](SECURITY.md).

Maintainer access is granted by the organization owners after sustained contributions and demonstrated care for reviews, security and maintenance. Owners can reassign responsibilities or remove access when a maintainer steps down or cannot meet those responsibilities. When leadership changes, record the handoff publicly, update CODEOWNERS and transfer release and infrastructure access deliberately.

Sponsorship supports maintenance, security work, testing and releases. Funding does not grant control over technical decisions, bypass review requirements or guarantee particular fixes. Maintainers disclose relevant conflicts of interest when reviewing a funded change. Project conduct is governed by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
